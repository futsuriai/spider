# Court card figures

`court/figures/` holds the Jack, Queen and King figures. Each file is the top half of a
figure, cropped from the "SVG-cards 1.3" vector card set (one file per card), with the
built-in corner text and the large corner suit removed.

Licence: the source set is listed as CC0 on OpenGameArt ("Playing Cards (Vector & PNG)",
by Byron Knoll). Its own files are labelled SVG-cards 1.3 (David Bellot), which is LGPL 2.1
(see `LICENSE-svg-cards.txt`). The upstream licence status is not fully verified, so check
